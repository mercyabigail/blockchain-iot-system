# Blockchain-Based Identification and Verification System

A blockchain-based IoT device identification and verification system developed using Ethereum.

## Technologies

- Solidity
- Ethereum
- Ganache
- Web3.py
- Python

## Features

- Device Registration
- Device Authentication
- Device Status Query
- Device Revocation
- Blockchain Event Logging

## Project Structure

```
contracts/
devices/
scripts/
build/
```
